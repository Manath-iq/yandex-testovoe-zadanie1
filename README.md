# Экран билета — Telegram Mini App

Тестовое задание: экран «Новая поездка» и экран «Мои билеты» (электронный билет на общественный транспорт) в виде веб-приложения для Telegram.

> **Это образец интерфейса.** Поверх билета крупно выведен водяной знак «ОБРАЗЕЦ», а под таймером написано «Образец. Не является проездным документом».

## Сценарий

1. **Новая поездка.** Тип транспорта (автобус или трамвай), номер маршрута, регистрационный и бортовой номер, перевозчик, направление, срок действия (30/60/90 мин), цена и количество билетов. Итоговая сумма считается сразу.
2. **Готово.** В Telegram это нативная `MainButton`, в браузере своя кнопка. Проверяется обязательный номер маршрута и цена: ошибка показывается под полем, поле вздрагивает, срабатывает хаптика.
3. **Мои билеты.** Экран билета строится из введённых данных, пустые необязательные поля скрываются. «Назад» (своя стрелка или `BackButton` Telegram) возвращает к форме, где сохранены данные и позиция прокрутки.
4. **Недавние поездки.** Последние 5 заполнений показываются чипсами над формой, по нажатию форма заполняется ими.

Форма и открытый билет хранятся в `localStorage`, поэтому переживают перезапуск мини-аппа.

**Демо:** https://manath-iq.github.io/yandex-testovoe-zadanie1/
**Бот:** [@testovoe_yandex1_bot](https://t.me/testovoe_yandex1_bot), кнопка «Билет» в меню открывает мини-апп

## Что внутри

- `index.html`, `styles.css`, `app.js`: чистые HTML/CSS/JS, без сборки и зависимостей.
- Шрифт YS Text подключается с `yastatic.net`, цифры таймера набраны Barlow Condensed (Google Fonts).
- Все размеры заданы в `rem`, а `1rem` равен 1/39.3 ширины экрана, поэтому макет (393pt, iPhone 15/16 Pro) масштабируется пропорционально и выглядит одинаково на любом телефоне.
- Таймер работает на `requestAnimationFrame`: минуты, секунды и сотые, а обновляются только изменившиеся ячейки. После истечения шапка билета становится серой, а кнопка «обновить» выпускает новый образец.
- Поля очищаются прямо при вводе: регистрационный номер переводится в верхний регистр, в бортовой номер и цену попадают только цифры. Enter переводит фокус к следующему полю, а шрифт полей не меньше 16px, чтобы iOS не увеличивала страницу при фокусе.
- Перфорация сделана одним `radial-gradient`: 11 полукругов с шагом 1/10 ширины карточки.
- Иконки нарисованы вручную на inline SVG.

## Интеграция с Telegram

- `Telegram.WebApp.ready()` / `expand()`, на iOS и Android включается `requestFullscreen()` (Bot API 8.0+).
- Цвета шапки, фона и нижней панели Telegram совпадают с градиентом интерфейса.
- `disableVerticalSwipes()`, чтобы прокрутка не сворачивала мини-апп.
- Отступы берутся из `--tg-safe-area-inset-*` и `--tg-content-safe-area-inset-*`, для обычного браузера есть запасной вариант `env(safe-area-inset-*)`.
- Хаптика на нажатиях, «Назад» закрывает мини-апп, «Поддержка» показывает `showAlert`.

## Подключение к боту

1. В [@BotFather](https://t.me/BotFather): `/mybots` → бот → **Bot Settings → Configure Mini App → Enable Mini App**, указать URL демо.
2. Либо **Menu Button** с тем же URL.

## Кэш

GitHub Pages отдаёт файлы с `max-age=600`, а Telegram держит кэш ещё дольше. Поэтому `styles.css` и `app.js` подключены с версией в ссылке (`?v=<хэш>`). После правок её нужно обновить:

```bash
git hash-object styles.css app.js | cut -c1-8
```

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080` в мобильной эмуляции DevTools (например, 393×852).
