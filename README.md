# Экран билета — Telegram Mini App

Тестовое задание: вёрстка экрана «Мои билеты» (электронный билет на общественный транспорт) в виде веб-приложения для Telegram.

> **Это образец интерфейса.** Данные демонстрационные, а на билете выводится строка «Образец. Не является проездным документом».

**Демо:** https://manath-iq.github.io/yandex-testovoe-zadanie1/
**Бот:** [@testovoe_yandex1_bot](https://t.me/testovoe_yandex1_bot), кнопка «Билет» в меню открывает мини-апп

## Что внутри

- `index.html`, `styles.css`, `app.js`: чистые HTML/CSS/JS, без сборки и зависимостей.
- Шрифт YS Text подключается с `yastatic.net`, цифры таймера набраны Barlow Condensed (Google Fonts).
- Все размеры заданы в `rem`, а `1rem` равен 1/39.3 ширины экрана, поэтому макет (393pt, iPhone 15/16 Pro) масштабируется пропорционально и выглядит одинаково на любом телефоне.
- Таймер работает на `requestAnimationFrame`: минуты, секунды и сотые, а обновляются только изменившиеся ячейки. Время выпуска демо-билета хранится в `localStorage`, после истечения шапка билета становится серой, а кнопка «обновить» выпускает новый образец.
- Перфорация сделана одним `radial-gradient`: 11 полукругов с шагом 1/10 ширины карточки.
- Иконки нарисованы вручную на inline SVG.

## Интеграция с Telegram

- `Telegram.WebApp.ready()` / `expand()`, на iOS и Android включается `requestFullscreen()` (Bot API 8.0+).
- Цвета шапки, фона и нижней панели Telegram совпадают с градиентом интерфейса.
- `disableVerticalSwipes()`, чтобы прокрутка не сворачивала мини-апп.
- Отступы берутся из `--tg-safe-area-inset-*` и `--tg-content-safe-area-inset-*`, для обычного браузера есть запасной вариант `env(safe-area-inset-*)`.
- Хаптика на нажатиях, «Назад» закрывает мини-апп, «Поддержка» показывает `showAlert`.

## Подключение к боту

1. В [@BotFather](https://t.me/BotFather): `/mybots` → бот → **Bot Settings → Configure Mini App → Enable Mini App**, указать URL демо.
2. Либо **Menu Button** с тем же URL.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080` в мобильной эмуляции DevTools (например, 393×852).
